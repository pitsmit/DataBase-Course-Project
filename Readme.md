# 🏋️‍♂️ Приложение для управления деятельностью спортивного зала

## 🎯 О проекте

Комплексное решение для управления тренировочным процессом, расписанием и инфраструктурой спортивного зала с гибкой системой ролей и разграничением доступа.

## 👥 Ключевые роли пользователей

* клиент
* тренер
* администратор

## ✨ Функциональные возможности

Приложение позволяет гибко настраивать расписание тренировок,
учитывать персональные параметры клиентов, выставлять графики работы
залов и объектов инфраструктуры.

## 🛠 Технологический стек

* TS
* PostgreSQL

Приложение использует JSONWEBTOKEN и имеет различные роли на уровне 
базы данных.

## 🚀 План развития

* Создание графического веб-интерфейса
* Использование базы данных временных рядов InfluxDB
* Добавление функционала по управлению другими объектами зала
