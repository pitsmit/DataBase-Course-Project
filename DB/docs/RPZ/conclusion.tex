\chapter*{ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}

Цель курсовой работы была достигнута: разработано программное обеспечение с использованием
базы данных для автоматизации деятельности спортивного зала

Решены все поставленные задачи:

\begin{itemize}[label=—]
	\item сформулированы ограничения предметной области;
	\item проанализированы существующие решения;
	\item спроектирована база данных;
	\item спроектированы способы взаимодействия с базой данных;
	\item разработана база данных и приложение доступа к базе данных;
	\item проведено исследование разработанной базы данных.
\end{itemize}

В ходе исследование было обнаружено, что применение индексов существенно уменьшает время выполнения запросов
к базе данных.
