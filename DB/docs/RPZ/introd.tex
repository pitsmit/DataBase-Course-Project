\chapter*{ВВЕДЕНИЕ}
\addcontentsline{toc}{chapter}{ВВЕДЕНИЕ}

Спортивным залам необходимо управлять внутренними бизнес процессами. Для эффективного решения этой задачи требуется 
программное обеспечение, облегчающее контроль и управление залом. Оно повысит качество обслуживания и оптимизирует 
работу зала, сделав ее более удобной для администраторов, тренеров и клиентов.

\textbf{Цель данной работы} — разработка и реализация информационной системы, прикладные
программы которой используют данные, хранящиеся в базе данных, для автоматизации
деятельности спортивного зала.

Для достижения данной цели необходимо решить следующие задачи:

\begin{itemize}[label=—]
	\item уточнить требования и формулировку ограничений предметной области;
	\item проанализировать существующие решения;
	\item спроектировать базу данных;
	\item спроектировать способы взаимодействия с базой данных;
	\item разработать базу данных и приложение доступа к базе данных;
	\item провести исследование разработанной базы данных для определения эффективности индексации.
\end{itemize}
