\chapter*{РЕФЕРАТ}

Рассчетно-пояснительная записка содержит 63 страницы, 14 иллюстраций, 15 таблиц, 17 источников, 3 приложения.

Ключевые слова: спортивный зал, клиент, тренер, база данных, ролевая модель, система управления базами данных, 
TypeScript, PostgreSQL, индекс.

Темой данной курсовой работы является исследование предметной области спортивных залов и комплексов.
Целью является разработка программного обеспечения с использованием базы данных, 
реализующего управление спортивным залом.
Результатами работы является программный продукт на языке TypeScript, использующий систему управления
базами данных PostgreSQL, содержащий сценарии использования для клиентов, тренеров
и администраторов спортивного зала, а также исследование влияния применения различных типов индексов в базе
данных на время выполнения запросов к ней.
